① 初识会计 · 建立专业认知 · 建议 4–6 学时
  • 📘
    会计是什么教材 · 通识

    会计是企业经济活动的「商业通用语言」，把经营活动翻译成可比、可验证的数字信息，保障交易信任链。

    对应 KB：会计是什么（知识 1.1）
  • 📘
    会计四大基本假设与八大质量要求教材 · 基础

    假设：会计主体、持续经营、会计分期、货币计量；质量：可靠性 / 相关性 / 可比性 / 谨慎性 等八项。

    对应 KB：会计基本假设、会计信息质量（知识 1.2）
  • 📘
    会计等式 · 借贷规则 · 三大报表教材 · 核心

    静态等式 资产＝负债＋所有者权益；有借必有贷，借贷必相等；三张报表的勾稽关系。

    对应 KB：会计等式、借贷规则、财务报表（知识 1.3）
  • 📖
    会计发展史与数智化趋势阅读 · 拓展

    从手工 → 电算化 → 信息化 → 数智化；帕乔利复式簿记与中国「四柱清册」。

    对应 KB：会计发展史（知识 1.6）
  • 🧪
    巩固练习 · 知识维度 11 题习题

    从「习题练习」选「知识」模块开始，覆盖假设 / 等式 / 借贷 / 报表 / 要素 / 计量属性。

🎯 学习目标：理解会计本质、掌握基本概念，能区分财务会计 / 管理会计 等分支。
② 专业解码 · 培养方案与专业分支 · 建议 3–5 学时
  • 📘
    会计五大分支教材 · 框架

    ① 财务会计 ② 管理会计 ③ 审计学 ④ 税务会计 ⑤ 会计信息系统；理解不同分支的边界与协同。

    对应 KB：会计分支（知识 1.4）
  • 📘
    毕业要求九大维度教材 · OBE

    思想品德、学科知识、专业知识、专业应用能力、数据应用能力、信息能力、创新创业、合作沟通、持续发展。

    对应 KB：毕业要求（知识 1.5）
  • 📖
    CIMA 方向班 · 本校特色项目招生亮点

    本校 CIMA 方向班是特色项目（独立招生选拔），大二加修专属课程，毕业可获 CIMA 基础阶段证书进入 CGMA 通道。

    对应 KB：CIMA（规划 4.1）
  • 📖
    会计证书体系（国内 + 国际）阅读 · 规划

    初级（大一可报）/ 中级 / CPA / 税务师；国际 ACCA / CMA。推荐路径：初级 → ACCA → CPA。

    对应 KB：证书（规划 4.1）
  • 🧪
    巩固练习 · 知识 + 规划 维度习题

    建议做完「知识」11 题，再做「规划」5 题；专业解码侧重毕业要求与证书认知。

🎯 学习目标：看懂培养方案，知道所学与未来方向的对应关系。
③ 行业能力 · 五维能力与 AI 时代 · 建议 4–6 学时
  • 📘
    五维能力模型教材 · 核心

    专业能力（准则判断）、数据能力（Excel/SQL/Python/BI）、AI 能力（Prompt/RPA）、业务能力（业财融合）、学习能力（持续学习）。

    对应 KB：五维能力（能力 2.3）
  • 📘
    AI 冲击与不可替代能力教材 · 前瞻

    可替代：凭证录入、对账、报表编制、发票 OCR；不可替代：专业判断、商业解释、跨部门沟通、伦理决策。

    对应 KB：AI 冲击（素养 3.2）
  • 📖
    岗位地图：从出纳到 CFO 的多条路径阅读 · 拓展

    企业财务、事务所、金融机构、公务员、新兴岗位（财务 BP、智能风控、数据分析师、ESG 专员）。

    对应 KB：岗位（规划 4.1）
  • 📖
    会计诚信与合规底线阅读 · 红线

    不伪造、不隐瞒、不迎合；违法红线：虚假财务报告、隐匿收入、虚假发票。案例：康得新、康美药业。

    对应 KB：会计诚信（素养 3.1）
  • 🧪
    巩固练习 · 能力 + 素养 维度习题

    「能力」5 题重数据 / 判断；「素养」5 题重伦理 / 终身学习 / AI 协作。

🎯 学习目标：建立"专业 + 数据 + AI + 业务 + 学习"五维竞争力，识别自身护城河。
④ 规划落地 · 四年个人发展路径 · 建议 2–3 学时
  • 📘
    大一学年规划（打基础）教材 · 行动

    高数、英语、会计学原理、计算机基础；目标：通过初级会计（次年 5 月）、加入 1 个社团 / 1 个学科竞赛团队。

    对应 KB：大一规划（能力 2.2）
  • 📘
    考研路径：MPAcc / 学硕 / 审计硕 / 税务硕教材 · 进阶

    MPAcc：199 管理类联考 + 英语二 + 政治 + 复试；学硕：政治 + 英语一 + 数学三 + 专业课；大三上定方向、大三下系统复习。

    对应 KB：考研留学（规划 4.3）
  • 📖
    留学方向（英 / 澳 / 美 / 港）阅读 · 多元

    语言考试（雅思 / 托福 / GMAT）、GPA、实习 / 科研；大三上确定国家与方向。

    对应 KB：考研留学（规划 4.3）
  • 📖
    CIMA / 证书 / 实习 / 竞赛组合阅读 · 包装

    证书 + 实习 + 学科竞赛 + 第二课堂，形成差异化简历；建议大二起每学期 1 段相关经历。

    对应 KB：CIMA、证书、岗位（规划 4.1）
  • 🧪
    巩固练习 · 规划维度 5 题习题

    侧重路径选择与时间节点；做完参加「智能考核」形成 OBE 四维达成度报告。

🎯 学习目标：把模糊的"未来"拆成四年可执行清单，立即开始第一步。
